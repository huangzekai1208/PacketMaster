# Web 对话即时发送设计

日期：2026-07-29

## 目标

用户点击发送或按 Enter 后，消息立刻显示在对话区；模型和后端回复仍异步等待，避免网络请求延迟阻塞输入反馈。

## 方案

- 仅对未完成分析时的普通会话消息使用乐观更新。
- `onMutate` 向 React Query 的当前会话缓存插入带临时 ID 的用户消息，并清空输入框。
- 请求成功后刷新会话，以服务端持久化消息为准；请求失败时回滚到发送前缓存并显示既有错误提示。
- 已完成分析后的报告追问继续使用独立问答历史，不伪造服务端问答记录。

## 验收

- 在挂起的消息请求期间，用户消息立即可见。
- 失败时临时消息被撤回，成功时服务端消息不会重复显示。
- 不改变 API 契约、消息脱敏边界或已有会话恢复逻辑。
